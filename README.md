# wxcn-svelte

`wxcn-svelte` is a shadcn-svelte registry project for weather, tide, and moon forecast cards.

## Endpoints

- Weather: NWS `api.weather.gov`, open data and free for any purpose.
- Tides: NOAA CO-OPS predictions API.
- Moon: local lunar phase calculation, no third-party endpoint required.

## Development

```sh
pnpm install
pnpm dev
pnpm check
pnpm build
```
