# React preview

Run `pnpm install` and `pnpm dev:react` from the workspace root. `pnpm build:react` typechecks and builds the native Vite app. This standalone Vite app is the React SSR, hydration, and interaction test harness; the same native cards are served by Astro at `/react`, with component docs at `/react/docs/components`. Controls cover theme, units, size, density, detail, icon library, and atmospheric motion. All displayed data is labeled as fixtures.
